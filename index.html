rclone Drive Backup

A private, single-user tool for backing up one personal Google Drive account.

What it is

This is my personal configuration of rclone, an open-source command-line program for copying files between cloud storage and local disks. Once a month, it copies the contents of my own Google Drive to a hard drive on my home server.

Who can use it

Only me. It is not a public service, it has no other users, and it is not offered to anyone else.
